# 6. Important Architecture Rules

These rules must remain unchanged during V7.9.

---

## Rule 1

ExecutionGraph is the orchestration contract.

No component should directly orchestrate agents.

---

## Rule 2

ExecutionEngine owns execution.

Runtime controls lifecycle.

Agents execute tasks only.

---

## Rule 3

Runtime and Agents remain separated.

Runtime:

- Scheduling
- Policies
- Reliability
- Observability
- Recovery


Agents:

- Domain execution
- Specialized intelligence


---

## Rule 4

Every new capability requires:

```

Implementation

*

Unit Tests

*

Integration Tests

*

Documentation Update

```
