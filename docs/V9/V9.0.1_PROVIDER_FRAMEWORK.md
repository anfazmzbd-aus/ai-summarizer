## Provider contract
    Introduce dynamic provider discovery and creation.

    After this package, the runtime will no longer know about concrete providers.

    Future flow:
    Execution Runtime
            |
            ↓
    Provider Factory
            |
            ↓
    Provider Registry
            |
            ↓
    Concrete Provider
    (OpenAI / Azure / Ollama / Mock)

## Factory usage
    The factory becomes the single creation point for providers.
        provider = ProviderFactory.create(config)

    Design

    Factory responsibilities:

    Accept ProviderConfig
    Resolve provider type
    Create provider instance
    Validate unsupported providers
    Avoid provider-specific logic leaking into runtime

    Architecture:
    ProviderConfig
        |
        ↓
    ProviderFactory
        |
        ↓
    Provider Creator Registry
        |
        ↓
    Provider Instance
